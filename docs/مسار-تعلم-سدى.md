# تقرير تعلّم سُدى — مسار عملي من أول سطر

> هذا التقرير يشرح شلون تتعلم سُدى، شنو ممكن تستفاد منها، وشنو حدودها
> الحقيقية. سُدى حاليًا نموذج أولي تعليمي؛ لا تعتبرها مترجمًا أصليًا أو
> لغة جاهزة للإنتاج أو بديلًا مثبتًا لبايثون.

## 1. شنو سُدى؟

سُدى لغة برمجة تجريبية عربية أولًا. تكتب الأوامر بكلمات مثل `إذا` و`لكل`
و`دالة`، وبعدها تمر الشيفرة بمراحل محددة:

```text
ملف UTF-8 ← محلل معجمي ← محلل نحوي ← شجرة AST
          ← مولّد bytecode ← مدقق المكدس ← آلة افتراضية ببايثون
```

المترجم لا يحول البرنامج إلى كود معالج أصلي. الـbytecode تعليمات خاصة بسُدى،
والآلة الافتراضية (VM) المكتوبة ببايثون هي اللي تنفذها. بعض العمليات الرقمية
الثابتة والآمنة تنحسب وقت الترجمة لتقليل تعليمات التنفيذ. أما العمليات اللي
تسبب خطأ أو تتجاوز حدود العدد، فتبقى حتى يبلغ عنها التشغيل بالمكان المناسب.

## 2. لمن تفيد؟

- **للمبتدئ العربي:** يتعلم المتغيرات والشروط والحلقات والدوال بأسماء عربية،
  من غير ما يضطر يحفظ كلمات مفتاحية إنجليزية أول يوم.
- **للمعلم أو الطالب:** يقدر يشرح خطوات كتابة البرنامج، وتحليله، وتحويله
  لتعليمات، وتشغيله بالـVM.
- **للمهتم ببناء اللغات:** يقرأ شيفرة lexer وparser وcompiler وbytecode وVM
  ويشوف شلون تتصل المراحل ببعضها.
- **للتجربة على جهاز بسيط:** النواة مكتوبة ببايثون وما تحتاج مكتبات خارجية
  وقت التشغيل. حجمها الفعلي يتغير حسب نسخة Python وأداة التثبيت؛ لهذا ما
  نعد بحجم ثابت لكل الأجهزة.
- **للتدرب على قراءة الأخطاء:** سُدى تعرض أخطاء ترجمة وتشغيل مع رقم السطر،
  وتوقف البرامج اللي تتجاوز حدودها المحددة.

هذه فوائد تعليمية وتجريبية، مو ضمان توظيف أو أداء أو جاهزية تجارية. كتابة
اللغة بالعربي ما تعني أن اللهجة تُحلل كأنها نص حر: لازم تلتزم بكلمات وقواعد
واضحة ومحددة.

## 3. المتطلبات والتثبيت

- Python 3.11 أو أحدث.
- Git عند التثبيت المباشر من GitHub.
- ملفات المصدر بترميز UTF-8.

تثبيت المترجم بأمر واحد:

```bash
python -m pip install "git+https://github.com/rayman938/suda-lang.git"
```

فتح الواجهة الخفيفة المبنية على Tkinter:

```bash
suda gui
```

واجهة PySide6 اختيارية، وتحتاج تنزيل حزمة أكبر:

```bash
python -m pip install "git+https://github.com/rayman938/suda-lang.git#egg=suda-lang[qt]"
suda gui --backend pyside6
```

إذا لم تدعم أداة pip صيغة extras مع رابط Git، نزّل المستودع ثم ثبّت الإضافة:

```bash
git clone https://github.com/rayman938/suda-lang.git
cd suda-lang
python -m pip install ".[qt]"
suda gui --backend pyside6
```

الصوت خيار إضافي يستعمل أصوات النظام الموجودة عندك؛ البرنامج ما ينزل ولا
يوزع تسجيلات صوت أشخاص:

```bash
python -m pip install ".[voice]"
```

للنطق العربي لازم يكون عند نظام التشغيل صوت عربي مثبت. إذا ما متوفر، اختَر
التعليق الإنجليزي أو ثبّت حزمة صوت عربية من إعدادات النظام. تبقى النصوص
المقروءة ظاهرة حتى إذا ماكو صوت.

## 4. أول جلسة تعلّم

افتح الاستوديو بـ `suda gui`. راح تلاقي:

1. **المحرر والتشغيل:** عدّل المثال، افتح ملفات `.sada`، احفظها، وشغّلها.
2. **تعلم خطوة بخطوة:** دروس عن القيم والشروط والحلقات والدوال والمجموعات
   والـbytecode.
3. **مشاهد متحركة:** رسوم أصلية تتحرك وتوضح الفكرة، مع شريط تقدم وتعليق
   صوتي اختياري من صوت النظام.

المشاهد داخل التطبيق رسوم تعليمية متحركة وليست ملفات MP4 منفصلة. محتواها
مولد من الرسومات والشرح الأصليين للمشروع، من دون وجوه أو مقاطع منسوخة من
مواقع أو أشخاص. بهالطريقة ما نستخدم فيديوهات أو أصوات طرف ثالث؛ وتظل
الرسومات الأصلية خاضعة لملف الحقوق في المستودع، وما ندّعي أن داخل المشروع
أفلامًا مصورة كاملة.

ابدأ بهالمثال واحفظه بملف `hello.sada`:

```text
اسم = "العالم"
اطبع("هلا بيك يا", اسم)
```

شغّله من سطر الأوامر:

```bash
suda run hello.sada
```

المتوقع:

```text
هلا بيك يا العالم
```

## 5. مسار الدروس والتمارين

### الدرس الأول: الإخراج والنصوص

`اطبع(...)` تعرض القيم بالترتيب، وتفصل بين الوسائط بمسافة. النص يكتب بين
علامتي اقتباس مزدوجتين.

```text
اطبع("صباح الخير")
اطبع("اللغة", "سُدى")
```

**جرّب:** غيّر التحية إلى اسم مدينتك. راقب أن النص لازم يبقى داخل الاقتباس.

### الدرس الثاني: المتغيرات والأنواع

الإسناد ينشئ المتغير أول مرة، وبعدها يبدل قيمته. ماكو تصريح نوع إلزامي.

```text
اسم = "زينب"
محاولات = 3
ناجح = صحيح
نتيجة_اختيارية = لا_شيء
اطبع(اسم, محاولات, ناجح)
```

استخدم `ثابت` لما تريد تمنع إعادة إسناد الاسم:

```text
ثابت حد_المحاولات = 4
```

الثابت يمنع تغيير الاسم إلى قيمة ثانية؛ لكنه ما يمنع تعديل محتويات قائمة
أو قاموس محفوظة داخله.

### الدرس الثالث: العمليات والشروط

```text
سعر = 12
عدد = 3
إذا سعر * عدد <= 40:
    اطبع("ضمن الميزانية")
وإلا:
    اطبع("تجاوز الميزانية")
```

العمليات الحسابية: `+ - * / // % **`. المقارنات:
`== != < <= > >=`. استخدم `و` و`أو` و`ليس` للشروط المركبة. `و` و`أو`
قصيرة الدائرة؛ ما تحسب الطرف الثاني إذا الطرف الأول حسم النتيجة.

**جرّب:** غيّر السعر أو العدد، وخلي شرطًا ثانيًا يستخدم `و`.

### الدرس الرابع: الحلقات

```text
مجموع = 0
لكل رقم في مدى(1, 6):
    مجموع = مجموع + رقم
اطبع(مجموع)
```

الناتج `15`؛ `مدى(1, 6)` يتوقف قبل 6. `طالما` تكرر ما دام الشرط صحيح.
استخدم `اكسر` للخروج من الحلقة أو `استمر` للانتقال للدورة التالية.

**جرّب:** اجمع الأعداد الزوجية فقط، وتحقق بالشرط قبل الإضافة.

### الدرس الخامس: الدوال والنطاق

```text
دالة مساحة_مستطيل(طول, عرض):
    أرجع طول * عرض

نتيجة = مساحة_مستطيل(5, 3)
اطبع(نتيجة)
```

الوسائط محلية للدالة. الإسناد داخلها محلي، والاسم غير المحلي يبحث في العام
ثم المكتبة. إذا انتهت الدالة من دون `أرجع` ترجع `لا_شيء`. العودية مدعومة
لكن عمقها محدود.

### الدرس السادس: القوائم والقواميس

```text
مواد = ["دفتر", "قلم"]
أضف(مواد, "مسطرة")
اطبع(مواد[0], طول(مواد))

طالب = {"اسم": "علي", "درجة": 91}
اطبع(طالب["اسم"])
```

فهرسة القوائم تبدأ من صفر؛ الفهرس السالب يبدأ من النهاية. القاموس يحفظ
ترتيب الإدخال في النسخة الحالية. `أضف` تعدل القائمة، و`رتب` و`اعكس`
ينشئان قائمة جديدة. القيم المتداخلة مسموحة، لكن حدود العناصر مطبقة.

### الدرس السابع: الأخطاء والتشخيص

أخطاء مفيدة تتدرب عليها:

- اكتب اسمًا غير موجود حتى تشوف خطأ الاسم غير المعرّف.
- جرّب القسمة على صفر وشوف السطر اللي يشير له التشخيص.
- جرّب كتلة بمسافة بادئة غير متناسقة وشوف خطأ التحليل.
- غيّر `اطبع(1)` إلى `اطبع(1 / 0)` حتى تفرق بين خطأ ترجمة وخطأ تشغيل.

مو كل خطأ ينكشف قبل التشغيل: أمر `suda check` يترجم الملف لكنه ما ينفذ
كل فرع ولا يثبت صحة المدخلات اللي تظهر وقت التنفيذ.

### الدرس الثامن: تعرف على المترجم

احفظ هذا التعبير:

```text
قيمة = (2 + 3) * 4
```

المترجم يطوي الحساب العددي الثابت الآمن إلى قيمة `20`. اكتب:

```bash
suda compile hello.sada -o build/hello.sbc
suda disassemble build/hello.sbc
```

التعليمات الناتجة تبين شلون انتقلت من البرنامج المكتوب إلى bytecode. المدقق
يفحص أنواع التعليمات ومعاملاتها وتوازن مكدس القيم على مسارات القفز قبل
تشغيل bytecode.

## 6. مرجع سريع للقواعد

| العنصر | الصيغة |
|---|---|
| إسناد | `اسم = تعبير` |
| ثابت | `ثابت حد = 10` |
| شرط | `إذا شرط:` ثم كتلة مسافة بادئة |
| غير ذلك | `وإلا:` |
| حلقة بشرط | `طالما شرط:` |
| حلقة على قيم | `لكل قيمة في مجموعة:` |
| تعريف دالة | `دالة اسم(وسائط):` |
| إرجاع | `أرجع تعبير` داخل الدالة |
| قائمة | `[قيمة, قيمة]` |
| قاموس | `{"مفتاح": قيمة}` |
| تعليق | `# النص بعد العلامة لا ينفذ` |

التفاصيل الكاملة لأسبقية العوامل والأنواع والنطاق والأخطاء وتنسيق bytecode
موجودة في [دليل اللغة المرجعي](دليل-لغة-سدى.md). لا تستخدم هذا الجدول بدل
المواصفة إذا تحتاج دلالة دقيقة.

## 7. أوامر تستخدمها

```bash
suda --version
suda check hello.sada
suda run hello.sada
suda compile hello.sada -o build/hello.sbc
suda compile hello.sada -o build/hello.sbc --compress
suda disassemble build/hello.sbc
suda run-bytecode build/hello.sbc
suda gui
suda gui --backend pyside6
```

صيغة bytecode المضغوطة تستخدم zlib لتقليل التخزين والنقل أحيانًا. الضغط
اختياري، وقد يجعل الملف الصغير أكبر، ولا يشفره ولا يسرع تنفيذ البرنامج.

## 8. مشروع تخرج تدريبي: سجل مصاريف بسيط

هذا المثال يستخدم قائمة قواميس للحفظ داخل الذاكرة خلال تشغيل واحد؛ ما يخزن
البيانات بملف أو قاعدة بيانات.

```text
مصاريف = [
    {"وصف": "دفتر", "قيمة": 2.5},
    {"وصف": "قلم", "قيمة": 1.0},
    {"وصف": "حقيبة", "قيمة": 12.0},
]

المجموع = 0
لكل مصروف في مصاريف:
    اطبع(مصروف["وصف"], مصروف["قيمة"])
    المجموع = المجموع + مصروف["قيمة"]

اطبع("المجموع:", المجموع)
```

**توسعات مقترحة:** أضف عنصرًا، ارفض قيمة سالبة بشرط، اكتب دالة تجمع القيم،
واحسب أكبر مصروف. كل إضافة جديدة لازم تستخدم ميزة موثقة فعلًا.

## 9. قاموس مصطلحات

| المصطلح | معناه ببساطة |
|---|---|
| مترجم Compiler | يحول المصدر إلى تمثيل تعليمات |
| محلل معجمي Lexer | يقطّع النص إلى رموز مثل كلمة وعامل ورقم |
| محلل نحوي Parser | يتأكد أن ترتيب الرموز يطابق قواعد اللغة |
| AST | شجرة تلخص بنية البرنامج |
| Bytecode | تعليمات داخلية خاصة بسُدى |
| VM | آلة افتراضية تنفذ التعليمات |
| Optimizer | مرحلة تحسين؛ الموجود حاليًا طي محدود للثوابت الآمنة |
| Scope | النطاق اللي يبحث فيه البرنامج عن اسم متغير |
| UTF-8 | ترميز نص يدعم العربية |
| Sandbox | عزل أمني قوي؛ حدود سُدى الحالية ليست sandbox معتمدًا |

## 10. شنو مو موجود حاليًا؟

سُدى ما تنتج native machine code، وماكو دليل أنها أسرع من Python. وماكو
حاليًا أدوات متكاملة للهاتف أو سطح المكتب للمستخدم النهائي أو الويب أو AI،
ولا مدير حزم ونظام وحدات ومكتبات شبكة/ملفات في لغة المصدر. واجهة الاستوديو
تطبيق تعليمي لسطح المكتب، مو إطارًا لبناء برامج مستخدمين. لا تشغّل bytecode
مجهول المصدر على أنه آمن لمجرد وجود مدقق أو حدود موارد.

## 11. شلون تقيس تقدمك؟

بعد كل درس:

1. اكتب المثال من دون نسخ ثم شغّله.
2. غيّر قيمة واحدة وتوقع الناتج قبل التشغيل.
3. أضف حالة خطأ وتعامل وياها بتعديل البرنامج، مو بإخفاء رسالة الخطأ.
4. استخدم `suda disassemble` إذا تدرس المترجم.
5. شغّل الاختبارات بـ `python -m unittest discover -s tests -v`.
6. اقرأ دليل اللغة قبل اعتماد سلوك ما مشروح في هذا التقرير.
